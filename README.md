# TVHA releases

Release files of **TVHA**, a personal Home Assistant client for Android TV. The source code is not published here.

This repository only exists so the app can find its updates without a login: each release has the signed APK and a small `latest.json` (version, file name, SHA-256, size, short notes). The app only installs an update if it is signed with the same key as the installed app and its checksum matches, so downloading a file from here does nothing on its own.

Not an app for the Play Store; it is sideloaded onto one TV.
